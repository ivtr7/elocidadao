## 📋 Descrição do Projeto

O **Elo Cidadão** é um agente de impacto no WhatsApp que utiliza **Inteligência Artificial** para:

- 🔄 **Traduzir o "juridiquês" legislativo** em linguagem acessível
- 🎤 **Transformar denúncias informais** (inclusive em áudio) em documentos jurídicos oficiais
- 🚀 **Eliminar etapas burocráticas** ao conectar cidadãos diretamente às prefeituras
- 🌍 **Promover acessibilidade, inclusão e democracia digital** nos **5.570 municípios brasileiros**

### 🎯 Objetivo Principal

Conectar cidadãos diretamente às prefeituras através do WhatsApp, utilizando IA para simplificar processos burocráticos e tornar a participação cidadã mais acessível e inclusiva.

## 🛠️ Stack Tecnológica

O projeto é construído com foco em **escalabilidade**, **automação** e **integração via WhatsApp**.

### Backend & Automação

- **🐍 Python** – Processamento de dados, manipulação de textos e integrações com IA
- **🟢 Node.js** – Backend, rotas, serviços e automações

### Frontend

- **⚛️ React** – Interface web administrativa e ferramentas internas
- **🎨 Tailwind CSS** – Estilização moderna e responsiva
- **📦 shadcn/ui** – Componentes de UI reutilizáveis

### Integração WhatsApp

- **📱 Baileys** – Biblioteca utilizada para integração com o WhatsApp, permitindo:
  - ✅ Envio e recebimento de mensagens
  - ✅ Processamento de áudios
  - ✅ Envio e recebimento de documentos

### Inteligência Artificial

- **🤖 Google Gemini** – Modelo de IA utilizado para:
  - 📝 Interpretação de linguagem legislativa
  - 🎤 Compreensão de áudio (speech-to-text)
  - 📄 Geração de documentos oficiais
  - 💬 Assistência contextual ao usuário

### Banco de Dados

- **🗄️ Supabase** – Banco de dados utilizado para:
  - 💾 Persistência de mensagens
  - 📋 Armazenamento de denúncias
  - 👥 Gestão de usuários
  - 📊 Registros de processamento

## 🤖 Uso de Inteligência Artificial

A **IA é parte essencial** do Elo Cidadão em todas as etapas do processo:

| Funcionalidade | Descrição |
|----------------|-----------|
| 🎤 **Processamento de Áudio → Texto** | Conversão de áudios de denúncias em texto transcrito |
| 📝 **Conversão de Denúncias Informais** | Transformação de linguagem coloquial em linguagem jurídica formal |
| 📖 **Simplificação de Textos Legislativos** | Tradução do "juridiquês" para linguagem acessível ao cidadão comum |
| 📄 **Geração de Documentos Formais** | Criação automática de documentos oficiais prontos para envio |
| 💬 **Assistência Contextual** | Suporte inteligente ao usuário dentro do WhatsApp |

> 💡 A combinação do **Gemini** com fluxos de automação garante **precisão**, **acessibilidade** e **confiabilidade** em todas as operações.

## 📚 Fontes e Referências de Dados Abertos

Para validar o modelo e testar a solução, foram utilizados:

- 📜 **Projetos de lei** extraídos de portais de notícias
- 📚 **Conteúdos legislativos** de repositórios públicos
- 🏛️ **Documentos oficiais** de câmaras municipais

Esses dados servem como base para:
- 🔍 Interpretação de textos jurídicos
- ✂️ Simplificação de linguagem legislativa
- 🧪 Testes e validação do modelo de IA
